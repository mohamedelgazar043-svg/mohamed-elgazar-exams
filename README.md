# Mohamed Elgazar exams site

Static Arabic website of science exams and links by Mr. Mohamed Elgazar.

- Main site (Cloudflare Pages): https://mohamed-elgazar-exams.pages.dev/
- Working copy (GitHub Pages): https://mohamedelgazar043-svg.github.io/mohamed-elgazar-exams/

## Folders

- `site/` is the build served by the main Cloudflare site.
- `docs/` is the build served by GitHub Pages. Same content, with links pointing at the GitHub Pages address. Its canonical tags point to the main Cloudflare site.
- `generate_site.py` builds the pages.

## Notes

The GitHub Pages copy is a snapshot. It is updated by hand when the main site changes, not automatically.
